# Navigation fix

Bu versiyada bottom menu **React Navigation Bottom Tabs** ilə qurulub.
`react-native-paper BottomNavigation` içində nested stack problemi (Another navigator...) aradan qaldırılıb.

Run:
```bash
rm -rf node_modules package-lock.json
npm install
npx expo start -c
```

Əgər module tapmasa:
```bash
npx expo install @react-navigation/bottom-tabs
```
